# Consolidated Default Services, LLC

To compile the PUG Template Engine use Follow https://github.com/pugjs/pug or

1. Install Nodejs
2. Install `npm install pug`
3. then `npm install pug-cli -g`
4. then use `pug -w .\preprocessor\pug\views -o .\ -P` for Windows and `pug -w ./preprocessor/pug/views -o ./ -P` for unix/linux command in the terminal to render in html; resource https://github.com/pugjs/pug-cli
